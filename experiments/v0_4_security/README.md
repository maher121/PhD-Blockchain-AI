# V0.4 Experiment Record

This directory stores reproducibility snapshots generated by
`python -m src.pipeline_v04`. The experiment uses real operational records from
the V0.2 DataCo test split and controlled synthetic modifications. Its labels are
experimental ground truth, not native DataCo cybersecurity labels.

Deterministic experiment IDs encode the scenario, requested attack rate, severity,
and seed. Detailed per-record manifests remain under
`results/security/attack_manifests/` to avoid duplicating generated data here.
