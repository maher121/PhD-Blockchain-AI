## Leakage contract

Order-level features (`item_count_per_order`, `order_total_value`) are computed from the training split only. Outcome-adjacent columns (Delivery Status, Days for shipping (real), Order Status) are excluded from ML features. The default split strategy ``order_grouped`` keeps each `Order Id` in one split.
